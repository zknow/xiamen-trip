# 03 公共設施與教育文化

公共圖書館、大學校園、科普場館與文化設施，反映城市公共服務的配置方式與使用習慣。

## 3.1 廈門市圖書館

| 地點 | 特色 | 推薦原因 |
|---|---|---|
| 廈門市圖書館文化藝術中心館區 | 市級公共圖書館的重要館區 | 了解公共閱讀空間與文化服務 |
| 廈門市圖書館集美新城館區 | 集美新城的公共文化設施 | 觀察新城區的公共服務配置 |

值得留意閱讀座位、兒童閱讀區、數位資源、自助借還設備、活動空間與公共休息區。文化藝術中心館區位於廈門文化藝術中心，該中心其他場館見 3.4 與 3.6。

## 3.2 廈門大學思明校區

- 校園建築、綠地與公共空間。
- 校園景觀與步行環境。
- 大學與周邊街區的關係。
- 校園周邊餐飲、商業與學生生活。
- 高等教育機構與城市文化的連結。

校園入校規定可能調整。現行方式：透過微信公眾號「廈門大學訪客預約系統」實名預約，最早提前 3 日、每日 08:00／12:00／16:00 開放預約，熱門時段名額要先搶（2026-01 起校方研議調整規則，出發前以官方公告為準）。

## 3.3 集美學村

- 教育建築群與校園空間。
- 閩南及華僑文化相關建築特色。
- 教育設施與住宅、商業空間的連結。
- 傳統教育街區與集美新城的城市發展差異。

## 3.4 廈門科技館

- 位置：思明區體育路 95 號（廈門文化藝術中心內），地鐵 3 號線人才中心站。
- 開放：09:00–17:00（16:00 停止入館），週一閉館；門票約 ¥30–40，另收費展項另計。
- 科學互動展示、科普教育與親子活動。
- 與市圖書館同在文化藝術中心，可安排一起。

## 3.5 誠毅科技探索中心（集美）

| 項目 | 資訊 |
|---|---|
| 位置 | 集美區杏林灣路 339 號，地鐵 1 號線官任站 |
| 類型 | 室內大型科普樂園，國家 4A 級景區 |
| 票價 | 主展館約 ¥90，含特種影院的組合票另計（以現場或線上售票為準） |
| 體驗重點 | 展館規模大、可玩性高；與集美大悅城、集美新城公共設施同區可安排一天 |

## 3.6 其他公共文化設施

- **廈門文化藝術中心：** 圖書館、市博物館、科技館與公共活動空間集中在一處（圖書館部分見 3.1）。
- **集美新城公共設施：** 文化、教育與公共服務配置。
- **城市展覽館及地方文化場館：** 城市發展、歷史與規劃。
