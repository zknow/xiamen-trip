# 05 商業區與消費文化

大型商場、傳統商業街與街邊店並存，可比較品牌結構、消費價位與空間型態的差異。

## 5.1 大型商場

| 地點 | 特色 | 觀察重點 |
|---|---|---|
| SM 城市廣場 | 大型綜合購物商場 | 品牌、餐飲、娛樂與日常購物 |
| 廈門萬象城 | 現代化商業綜合體 | 品牌定位、空間設計與餐飲 |
| 寶龍一城 | 商場與生活消費空間 | 餐飲、娛樂及商業設施 |
| 中華城 | 鄰近老城區的商業空間 | 觀光街區與現代商場的互動 |
| 集美大悅城 | 集美區商業設施 | 新城區商業發展與居民消費 |

## 5.2 傳統商業街區

- **中山路步行街：** 傳統商業街、觀光人潮與老店。
- **八市周邊：** 市場小吃、傳統店家與居民採買。
- **沙坡尾：** 舊港區、創意商業、咖啡店及特色餐飲。
- **大同路周邊：** 傳統小吃、日常餐飲與老城區商業。
- **集美學村周邊：** 教育街區、學生消費與生活型餐飲。
