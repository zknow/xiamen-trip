# 11 生活方式差異

只記錄在廈門實際會遇到、且與台灣經驗明顯不同的地方。沒有明顯差異的項目不列，也不做完整制度對照。

| 體驗項目 | 當地實際情況 | 與台灣不同之處 | 怎麼體驗／注意什麼 |
|---|---|---|---|
| 行動支付 | 支付寶、微信支付涵蓋小店、市場攤位與公共服務 | 現金與信用卡可用範圍小很多 | 先開通可用的支付方式，市場攤位也掃碼付款 |
| 外送平台 | 同一平台同時做外送、到店優惠、買藥與跑腿 | 平台與線下商家綁得更深，到店也有平台價 | 同一家店比對平台價與店內價 |
| 快遞取件 | 住宅區、社區入口普遍設快遞櫃 | 台灣以超商取件為主 | 觀察小區集中取件點與取件碼流程 |
| 城市交通 | 地鐵、BRT、公車與共享單車並存，BRT 有專用道 | 台灣沒有 BRT 專用道形式 | 實際搭一次 BRT，看站體與轉乘動線 |
| 智慧旅宿 | 部分連鎖飯店可自助入住、房內語音控制、機器人送物 | 同價位在台灣較少見 | 訂房時確認自助機台與機器人服務範圍 |
| 公共圖書館 | 市級圖書館規模大，自助借還與數位資源完整 | 空間尺度與新館配置不同 | 看閱讀區、親子區與自助設備的實際使用 |
| 大學校園 | 入校需預約或查驗，校園自成生活圈 | 台灣校園多數對外開放 | 出發前查學校公告與入校方式 |
| 商場 | 大型綜合體結合餐飲、娛樂與超市，常與地鐵直結 | 百貨與量販分離的情況較常見 | 逛一次含超市的商場，看動線與樓層配置 |
| 社區服務 | 物業管理、快遞櫃與外送架集中在社區入口 | 台灣多由管理室與超商分擔 | 觀察小區入口的取件與外送暫存區 |
| 洗浴休閒 | 大型水會結合洗浴、泡池、汗蒸、餐飲與休息 | 台灣三溫暖、湯屋多為單一功能 | 先確認門票包含範圍與加購項目價格 |
| 平價飲食 | 沙茶麵、麵線糊等主食單價低、份量足 | 早餐與小吃的供應形式不同 | 從市場與老街區小店入門，先試單一品項 |
| 公共空間 | 山海步道、水岸綠地串連成連續步行網絡 | 台灣多為公園、河濱各自獨立 | 走一段步道，看它如何銜接道路與社區 |
