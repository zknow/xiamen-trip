# 02 智慧科技與數位生活

數位生活是理解當地城市運作方式的主要切入點，涵蓋支付、外送、物流、智慧設備與品牌生態。

## 2.1 行動支付與生活平台

| 平台 | 主要功能 | 觀察重點 |
|---|---|---|
| 支付寶 Alipay | 行動支付、交通及生活服務 | 支付功能與日常服務的整合 |
| 微信支付 | 餐飲、零售及生活服務付款 | 社交平台與支付生態 |
| 美團 | 外送、餐廳資訊及本地生活服務 | 線上平台與線下商家的整合 |
| 大眾點評 | 商家資訊、餐廳評價與消費參考 | 評價平台對消費選擇的影響 |
| 高德地圖 | 導航、交通與商家資訊 | 地圖與城市生活資訊的整合 |
| 滴滴出行 | 線上叫車與計程車 | 叫車流程、計價方式與候車點習慣 |
| 12306 | 中國鐵路官方購票服務 | 屬於跨城移動工具，非市內交通；觀察數位票務流程 |

## 2.2 外送、快遞與無接觸服務

| 服務 | 主要觀察點 | 體驗方式 |
|---|---|---|
| 美團外賣、餓了麼 | 同一平台涵蓋外送、到店優惠與跑腿 | 實際點一次外送，觀察配送速度與放置方式 |
| 菜鳥驛站、豐巢快遞櫃 | 社區集中取件與快遞櫃取件碼流程 | 收一件網購包裹，走完取件流程 |
| 自助取餐櫃、自助結帳 | 商場與餐飲的自動化 | 在便利商店或速食店用一次自助結帳 |
| 配送機器人 | 部分飯店與商場的機器人送物 | 記錄出現場所與使用情境 |

- 外送員在商場、住宅區與辦公大樓的取餐及交付方式。
- 外送平台與實體餐飲店的整合：同一家店平台上多有對應分店。

## 2.3 智慧設備與共享服務

| 類型 | 特色 | 觀察重點 |
|---|---|---|
| 智慧家電 | 智慧音箱、掃地機器人、智慧門鎖 | 智慧家庭產品的普及程度 |
| 商場服務 | 電子支付、自助點餐、自助結帳 | 商業服務的自動化 |
| 共享單車 | 哈啰、美團等品牌投放 | 投放密度與停放管理，以現場實際投放為準 |

自助入住、電子房卡、客房語音控制與飯店機器人見 [10 住宿與智慧飯店](10-住宿與智慧飯店.md)。

## 2.4 科技品牌與消費電子

| 門市 | 位置 | 特色 |
|---|---|---|
| 華為智能生活館（SM 三期） | 思明區 SM 廣場三期 | 華為全場景產品與智慧家居展示 |
| 華為旗艦店（廈門萬象城店） | 萬象城臨街獨棟 | 2025-07 開幕、獨棟雙層約 2,382 m²，福建省內最大的華為門店 |
| 小米之家（湖里 SM 廣場店） | 湖里區 SM 廣場 | 米家產品與智慧家庭生態鏈展示 |

- 手機、穿戴裝置、智慧家電與家庭網路可在同一門市一次看齊。
- 觀察智慧家庭設備之間的連動展示，比台灣門市的展示範圍大。

無人駕駛計程服務在其他城市商業化營運（蘿蔔快跑等），廈門是否可體驗：待確認。
