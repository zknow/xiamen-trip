# 02 智慧科技與數位生活

數位生活是理解當地城市運作方式的主要切入點，涵蓋支付、外送、物流、智慧設備與品牌生態。

## 2.1 行動支付與生活平台

| 平台 | 主要功能 | 觀察重點 |
|---|---|---|
| 支付寶 Alipay | 行動支付、交通及生活服務 | 支付功能與日常服務的整合 |
| 微信支付 | 餐飲、零售及生活服務付款 | 社交平台與支付生態 |
| 美團 | 外送、餐廳資訊及本地生活服務 | 線上平台與線下商家的整合 |
| 大眾點評 | 商家資訊、餐廳評價與消費參考 | 評價平台對消費選擇的影響 |
| 高德地圖 | 導航、交通與商家資訊 | 地圖與城市生活資訊的整合 |
| 12306 | 中國鐵路官方購票服務 | 屬於跨城移動工具，非市內交通；觀察數位票務流程 |

## 2.2 外送、快遞與無接觸服務

- 外送員在商場、住宅區與辦公大樓的取餐及交付方式。
- 住宅區及商業空間的快遞櫃與集中取件設施。
- 自助取餐櫃、自助結帳及智慧門禁。
- 外送平台與實體餐飲店的整合。
- 部分商場、飯店或商業空間的配送機器人。

## 2.3 智慧設備與共享服務

| 類型 | 特色 | 觀察重點 |
|---|---|---|
| 智慧家電 | 智慧音箱、掃地機器人、智慧門鎖 | 智慧家庭產品的普及程度 |
| 商場服務 | 電子支付、自助點餐、自助結帳 | 商業服務的自動化 |
| 共享服務 | 共享單車及其他共享設施 | 共享經濟與城市空間的關係 |
