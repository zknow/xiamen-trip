# 09 洗浴中心與湯泉

洗浴中心是這趟旅程值得保留的特色項目。部分大陸大型水會與湯泉將洗浴、泡池、汗蒸、休息區、餐飲及按摩等服務結合，與台灣常見的三溫暖、湯屋或溫泉設施不完全相同。

洗浴中心、水會、湯泉與天然溫泉並非同一概念；名稱包含「湯泉」也不代表一定使用天然溫泉水，實際設施須以場館公告為準。

## 9.1 場館類型與推薦方向

| 場館類型 | 主要特色 | 適合比較的面向 |
|---|---|---|
| 大型水會、養生會所 | 洗浴、按摩、休息與餐飲可能整合 | 複合式休閒服務與收費方式 |
| 湯泉休閒館 | 可能設有泡池、汗蒸及休息區 | 泡浴設施、休閒空間與套票 |
| 日月谷溫泉公園 | 溫泉度假型設施 | 與市區洗浴中心比較設施與消費模式 |
| 一般洗浴中心 | 淋浴、搓澡、汗蒸及按摩等服務 | 傳統洗浴文化與日常休閒消費 |

具體店名、營業狀態、地址與套票內容容易變動，應以最新官方資訊或商家頁面核實。

## 9.2 洗浴中心的服務特色

- **基本洗浴：** 淋浴、清潔與洗浴空間。
- **泡池及汗蒸：** 部分場館提供不同形式的泡浴與汗蒸設施。
- **搓澡與按摩：** 常見加購服務，通常需另外計費。
- **休息區：** 部分場館設有公共休息座位或躺椅。
- **餐飲服務：** 可能提供簡餐、飲料、自助餐或其他餐飲。
- **娛樂設施：** 依場館不同，可能設有影音、遊戲或其他休閒空間。

## 9.3 洗浴中心的收費結構

| 費用項目 | 注意事項 |
|---|---|
| 基本門票 | 確認包含哪些洗浴、泡池、汗蒸與休息設施 |
| 餐飲 | 確認是否包含餐飲，或需另外消費 |
| 搓澡與按摩 | 確認服務項目與價目表 |
| 過夜或延時 | 確認是否允許過夜、有無時限及延時費 |
| 假日與夜間價格 | 部分場館可能依日期或時段調整價格 |

## 9.4 與台灣休閒設施的差異

| 面向 | 大陸部分大型水會／湯泉 | 台灣常見三溫暖／湯屋 |
|---|---|---|
| 服務整合 | 可能結合洗浴、汗蒸、餐飲與休息 | 依店家而異，常見不同類型分開經營 |
| 空間規模 | 部分大型場館具複合式空間 | 從小型三溫暖到大型溫泉設施皆有 |
| 收費方式 | 可能採門票加購、套票或分級服務 | 可能按時段、房型、設施或服務收費 |
| 休息空間 | 部分場館設有公共休息區 | 依設施類型而異 |
| 餐飲服務 | 部分場館把餐飲納入整體消費 | 依設施類型而異 |

**住宿原則：** 洗浴中心作為休閒體驗，不以公共休息區取代正式住宿。若涉及過夜，須確認場館是否明確提供該服務。
