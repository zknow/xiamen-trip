# 廈門體驗攻略

> **定位：** 從台中出發，實際體驗廈門居民的日常生活、智慧科技、公共設施、交通建設、商業消費、飲食與休閒方式。
>
> **核心目標：** 發掘台灣較少見、沒有，或使用方式與生活情境不同的事物。以「值得體驗什麼、如何體驗、實際有什麼特色」為敘述方向。
>
> **住宿原則：** 以一般連鎖酒店為主要住宿選擇；洗浴中心、水會與湯泉是獨立的休閒體驗，公共休息區不取代正式住宿。
>
> **美食原則：** 以居民日常飲食為基礎，依「消費方式＋人均」分三層收錄：平價（人均 ≤¥60）、中上價位（人均 ¥60–200）、吃到飽（固定價位無限取用）。價格是選擇參考，不是唯一收錄標準。
>
> **攻略形式：** 素材蒐集與逐步完善階段。依主題整理，不排天數、不排路線、不寫事前準備。

## 收錄標準

- 能實際前往、使用、品嚐、參觀或感受。
- 對應台灣較少見、沒有，或使用情境不同的體驗。
- 有具體特色與推薦理由，不用「必去」「最好」等無依據說法。
- 名稱、位置、價格、營業狀態可追溯；未確認的項目標示「待確認」。
- 價格以人民幣區間標示，並註明是否易變動。
